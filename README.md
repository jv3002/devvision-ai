# Gestor de proyectos - backend api

API REST para la gestion de proyectos con autenticacion y control

## tecnologias 

1-. Node.js

2-. Express

3-. SQlite

4-. JWT (JSON Web Tokens)

5-. bcrypt

6-. dotenv

# funcionalidades

-- resgistro y login de usuarios 

-- autenticacion mediante JWT

-- roles (admin/user)

-- CRUD de proyectos

-- rutas protegidas

--validaciones y manejo de errores
